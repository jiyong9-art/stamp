# 에이원 직인 날인기

비밀번호로 잠근 날인기입니다. `app.enc`는 암호문이라 비밀번호 없이는 열 수 없습니다.

- **서류·도장은 서버로 보내지 않습니다.** 브라우저(폰·PC) 안에서만 열고 찍습니다. 이 저장소에는 암호문만 있습니다.
- 하던 작업은 다시 열 수 있게 **이 기기 브라우저에만 24시간** 남고, 24시간이 지나면 저절로 지워집니다. 공용 기기에서는 폰 잠금을 켜 두세요.
- 비밀번호 화면의 "이 폰에서는 다음부터 묻지 않기"는 **기본값이 꺼짐**입니다. 켜면 이 기기에 열쇠가 남으므로 공용 폰에서는 켜지 마세요.
- 앱은 **30분 동안 쓰지 않으면 저절로 잠기고**, 오른쪽 위 잠금 단추로 바로 잠글 수 있습니다.
- 화면은 에이원 영업 모바일(Sales)과 같은 브랜드(A1KOREA 남색 `#003A84`)로 맞췄습니다.
